# 📚 LinkLab — Learning Management System

LinkLab is a minimalistic and fresh-looking Learning Management System where teachers can manage subjects and tasks, while students can explore subjects, view tasks, and upload their solutions with ease.

## ✨ Features

- **Teacher Role**  
  - Create and manage subjects  
  - Post tasks for each subject  
  - Review student submissions  

- **Student Role**  
  - View available subjects  
  - Access task descriptions  
  - Upload solution files
